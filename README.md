# Web Snake Game 🐍

## Play the game

Open [https://anxaljk-sandbox.github.io/web-snake-game/](https://anxaljk-sandbox.github.io/web-snake-game/) in your
browser and start playing! 🎮

It is playable on mobile by swiping and on a Laptop by using the arrow keys.

I do, however, recommend playing it on Laptop since the screen is bigger and you can therefore achieve higher scores.

## Getting started

1. Clone the repository
2. Open the console in the repository's root directory
3. Enter `npm run dev`
4. Open the link in your console (probably [localhost:5173/web-snake-game](http://localhost:5173/web-snake-game/))  in your browser
5. Start playing / developing! 💻

## About the implementation

This is a side-project I started out of boredom with the goal to come back to the roots of web development and actually
doing something *myself*. The goal is to use AI only to review my code and to help me understand the logic (like
the [collision-detection](./doc/collision-detection.md)) better and implement it correctly.
